# [BetterServerDetails](https://pharaoh2k.github.io/BetterDiscordStuff/?plugin=BetterServerDetails "BetterServerDetails") Changelog

### 1.0.8
- Added a link to star the repository on GitHub at the bottom of the changelog popup

### 1.0.7
- Update notices from Pharaoh2k's plugins are now combined into one "Plugin Updater" notification with an Update All button, like BetterDiscord's own addon updater, instead of one popup per plugin
- The built-in updater steps aside while Plugin Hub is enabled and manages the plugin, so updates arrive reviewed through the hub

### 1.0.6
- Fixed the update notification staying stuck on screen after clicking Update, Dismiss or its close button, working around a BetterDiscord bug

### 1.0.5
- Fixed "Hide native tooltip" no longer hiding Discord's server tooltip after a Discord update
- The server details tooltip appears faster, since showing it no longer makes Discord restyle the whole app

### 1.0.4
- Fixed the auto-updater installing updates to the wrong location

### 1.0.3
- Improved updates manager reliability

### 1.0.2
- Updated to match Discord changes
- Improved update-checker

### 1.0.1
- BdApi related improvements (minor)
