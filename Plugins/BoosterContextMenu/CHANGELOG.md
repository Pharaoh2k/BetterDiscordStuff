# [BoosterContextMenu](https://pharaoh2k.github.io/BetterDiscordStuff/?plugin=BoosterContextMenu "BoosterContextMenu") Changelog

### 1.0.0
- Initial release
- Right-click a booster in a server's Server Boosts "Recent Activity" to open the same user menu as right-clicking their name in chat: profile, message, mention, roles, moderation actions, Copy User ID and the items other plugins add
- Works on boosts that were given, are expiring or have expired
- Automatic update checking with changelog display
