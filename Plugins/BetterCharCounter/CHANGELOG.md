# [BetterCharCounter](https://pharaoh2k.github.io/BetterDiscordStuff/?plugin=BetterCharCounter "BetterCharCounter") Changelog

### 1.0.3
- Update notices from Pharaoh2k's plugins are now combined into one "Plugin Updater" notification with an Update All button, like BetterDiscord's own addon updater, instead of one popup per plugin
- The built-in updater steps aside while Plugin Hub is enabled and manages the plugin, so updates arrive reviewed through the hub

### 1.0.2
- Fixed the character counter not showing on the message box after a Discord update

### 1.0.1
- Fixed the update notification staying stuck on screen after clicking Update, Dismiss or its close button, working around a BetterDiscord bug

### 1.0.0
- Initial public release
- Live character counter on the message box, with your limit (2,000 characters, or 4,000 with Nitro)
- Counts multi-line messages and long pastes exactly, including newlines and text past Discord's 4,500 character draft limit
- Counters on profile notes (256 characters), your custom status (128) and the "Message @user" box in profile popouts
- Turns yellow at 70% and red at 90% of the limit
- Optional threshold to only show the counter once you get near the limit
- Automatic update checking with changelog display
