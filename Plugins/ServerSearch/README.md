# ServerSearch

A BetterDiscord plugin that adds a search button to your server list, so you can find any server by name and jump straight to it.

![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)
![Status](https://img.shields.io/badge/status-active-success.svg)
![Discord](https://img.shields.io/badge/discord-BetterDiscord-7289DA.svg)

## 📖 Description

ServerSearch pins a search button below your server list. Click it, start typing, and the list narrows to the servers that match, best matches first. Press Enter or click a server to open it. It is the quickest way to reach a server buried in a long list or a closed folder.

## ✨ Features

- **🔍 Always in Reach**: The search button stays pinned below the server list, however far you scroll
- **⚡ Instant Results**: Filters your servers as you type, with the best matches first and the matching text highlighted
- **🔤 Forgiving Search**: Ignores case, accents and styled letters, so `cafe` also finds "Café" and "𝐂𝐚𝐟𝐞"
- **🅰️ Initials**: Finds servers by the initials shown on servers without an icon, like `phu` for "PlayStation Hackers United"
- **📁 Folder Aware**: Shows which folder each server is in and finds servers by their folder's name
- **🔔 Unread & Mentions**: Shows mention counts and unread dots next to each server
- **⌨️ Keyboard Friendly**: Arrow keys to select, Enter to open, Esc to close
- **🔄 Auto Updates**: Automatic update checking with changelog display every 24 hours

## 📦 Installation

1. Download [ServerSearch.plugin.js](https://raw.githubusercontent.com/Pharaoh2k/BetterDiscordStuff/main/Plugins/ServerSearch/ServerSearch.plugin.js)
2. Place the file in your BetterDiscord plugins folder:
   - Windows: `%appdata%\BetterDiscord\plugins`
   - macOS: `~/Library/Application Support/BetterDiscord/plugins`
   - Linux: `~/.config/BetterDiscord/plugins`
3. Enable the plugin in Discord Settings → Plugins

## 🚀 Usage

1. Click the magnifying glass button at the bottom of the server list
2. Type part of a server's name, its initials or the name of its folder
3. Pick a server with the arrow keys and press Enter, or click it
4. Press Esc, click outside the search or click the button again to close it

With nothing typed, the search lists all your servers in the same order as the server list.

## ⚙️ Settings

Access settings through Discord Settings → Plugins → ServerSearch ⚙️

- **Automatic Updates**: Checks for updates on startup and every 24 hours (enabled by default)
- **Check for Updates**: Manually check if a new version is available
- **View Changelog**: View the complete changelog for this plugin

## ⚠️ Important Notes

- Opening a server takes you to the channel you last had open there, just like clicking its icon
- Folder names only appear for folders you have named
- Some features may not work correctly if Discord updates their internal structure

## 🔧 Troubleshooting

### Search button not showing?
- Make sure the plugin is enabled in Discord Settings → Plugins
- Reload Discord (Ctrl+R) and check the Discord console (Ctrl+Shift+I) for error messages

### Update issues?
- Manually check for updates from the settings panel
- Re-download and replace the plugin file if automatic updates fail
- Check the Discord console (Ctrl+Shift+I) for error messages
