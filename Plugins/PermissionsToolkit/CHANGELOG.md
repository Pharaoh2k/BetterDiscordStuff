# [PermissionsToolkit](https://pharaoh2k.github.io/BetterDiscordStuff/?plugin=PermissionsToolkit "PermissionsToolkit") Changelog

### 1.0.0
- Initial public release
- View a user's total server permissions in their popout and profile
- Inspect a channel's permission overrides for every role and member
- Browse permissions role by role, including each role's members
- Compare two roles or two users side by side
- Look up every role and member that has a specific permission, with a trace of where it comes from
- Security Audit for dangerous @everyone permissions, too many admin roles and risky overwrites
- Permissions entries in server, channel and user context menus
- Localized in English, Spanish, Portuguese, German, Russian, French and Dutch
- Automatic update checking with changelog display
