# [ShowHiddenThings](https://pharaoh2k.github.io/BetterDiscordStuff/?plugin=ShowHiddenThings "ShowHiddenThings") Changelog

### 1.0.6
- Added a link to star the repository on GitHub at the bottom of the changelog popup

### 1.0.5
- Update notices from Pharaoh2k's plugins are now combined into one "Plugin Updater" notification with an Update All button, like BetterDiscord's own addon updater, instead of one popup per plugin
- The built-in updater steps aside while Plugin Hub is enabled and manages the plugin, so updates arrive reviewed through the hub

### 1.0.4
- Fixed the update notification staying stuck on screen after clicking Update, Dismiss or its close button, working around a BetterDiscord bug

### 1.0.3
- Fixed "Open in Mod View" missing from the user context menu after Discord starts

### 1.0.2
- Added a "View Changelog" button to the settings

### 1.0.1
- Fixed the auto-updater installing updates to the wrong location

### 1.0.0
- Initial public release
- Show member timeout icons in chat without timeout permissions
- Display invites paused tooltip in server list
- Access Mod View context menu option in all servers
- View your own profile in Mod View from context menu
- Display highest role information in mod view
- Automatic update checking with changelog display
- Settings panel with individual toggles for each feature
